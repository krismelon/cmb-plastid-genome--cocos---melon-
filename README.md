## A short description of how the genome was downloaded and uploaded to Galaxy

The NCBI record is "Cocos nucifera chloroplast, complete genome" with accession NC_022417.1 and a length of 154,731 bp.

The genome was downloaded in FASTA format and uploaded to UseGalaxy.org, where the Fasta Statistics tool was used to analyze its sequence information. The annotated GenBank/RefSeq record was used to examine the genes and other genomic features.

## Gene Content and Important Observations 

The *Cocos nucifera* chloroplast genome contains 130 genes, including 84 protein-coding genes, 38 tRNA genes, and 8 rRNA genes. Important genes include *rbcL, psaA, psbA, atpA, petB, rpoB, rpl2, and matK, which are involved in photosynthesis, energy production, and other chloroplast functions.

Important observations include the presence of intron-containing genes, duplicated genes within the inverted repeat (IR) regions, and pseudogenes such as pseudo-ycf1, rps19, and two copies of ycf15. These features show some of the structural changes that have occurred in the chloroplast genome.

## Productivity

Another student can repeat the analysis by following these steps:

1. Go to NCBI Nucleotide.
   
2. Search for accession **NC_022417.1**.
   
3. Open the *Cocos nucifera* complete chloroplast genome.
  
4. Download the sequence in **FASTA format**.
   
5. Open UseGalaxy.org and create a new history.
   
6. Upload the FASTA file to Galaxy.
   
7. Run the **Fasta Statistics** tool.
   
8. Record the genome length, sequence count, and GC content.
   
9. Check the annotated NCBI record for genes and other features.
    
10. Save the results and screenshots in the GitHub repository.
