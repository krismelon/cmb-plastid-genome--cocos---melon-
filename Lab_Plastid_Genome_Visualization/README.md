## Software Used

**OGDRAW (OrganellarGenomeDRAW)** was used to generate the graphical map of the *Cocos nucifera* plastid genome.

## OGDRAW Settings

The following settings were used to generate the plastid genome map:

* Map mode: Standard
  
* Genome map type: Circular
  
* Sequence source: Plastid
  
* Inverted repeat detection: Automatic
  
* GC content graph: Enabled
  
* Direction of transcription: Enabled
  
* Full legend: Enabled
  
* Output format: PNG

## Main Structural Features

The *Cocos nucifera* plastid genome is organized into four major regions: the Large Single-Copy (LSC) region, Small Single-Copy (SSC) region, and two inverted repeat regions, IRa and IRb. The map also shows protein-coding genes, tRNA genes, rRNA genes, gene transcription directions, and the GC content across the genome. The graphical map makes it easier to observe the organization and distribution of genes throughout the plastid genome.
